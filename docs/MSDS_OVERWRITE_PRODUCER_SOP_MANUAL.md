## 一、 角色使命、权限沙箱与裁执物理隔离原则 (Role & Mission & Boundaries)

1. **专注生产，绝不自审自裁**：
   - 覆写 Subagent 的唯一法定职责是：**以源文档事实为唯一真理，利用 MSDS-Engine 底座与万能编辑器原语，生产 100% 忠实原文、排版规范的 4 DOCX + 4 PDF 交付物**；
   - 裁执物理隔离：生产 Agent 绝不担任自己的审计法官！交付物产出后，必须交付主协调 Agent 与独立的敌手审计 Agent 进行深度敌手挑刺审验。

2. **【最高铁律】系统核心目录绝对只读与严禁硬编码 (SYS-01 & SYS-02)**：
   - 🛑 **未经人类用户明文批复授权，你绝对无权向以下系统核心目录及其子目录创建、修改、重命名或删除任何文件**：
     * `web/src/`（核心排版、通用编辑、流水线、识别与匹配引擎源码）
     * `web/templates/`（官方正式 Word/PDF 模板资产）
     * `web/scripts/`（中央主审计套件、通用校验工具等核心平台脚本）
   - 🛑 **业务可写作用域严格封闭**：你的写权限严格且唯一封闭在：
     * 目标产品交付物目录（如 `算法训练材料/TDS MSDS 重写版/<品类>/<型号>/`、`E:/冠志/TDS MSDS (2)/待处理文件/<型号>/`）；
     * 临时认知审计报告与会话草稿目录（`产出物审计报告/`、`brain/`、`scratch/`）。
   - 🛑 **严禁残留一次性脚本**：严禁在代码库根目录或 `web/` 目录下遗留任何带有特定型号名称的一次性临时拼装脚本（如 `build_<model>.mjs`、`patch_<model>.mjs`）。

3. **【唯一通道】官方 MCP 工具链唯一执行公理 (MCP-01 & MCP-02)**：
   - 🛑 **设立 MCP 为生产覆写唯一执行通道**：一切文档识别、几何手术、受控导出与质量审计操作，必须严格且唯一通过 `msds-engine-mcp` 官方工具链（或其同构网关驱动器 `msds_mcp_gateway.mjs`）受控执行；
   - 🛑 **严禁私写脚本直改受控产出物**：严禁绕开 MCP 协议，通过私自编写 python-docx、原生 DOM/XML 编辑或调用任意非受管脚本直接修改交付物。

4. **【停机申报】底座通用缺陷申报与升级闭环机制 (SYS-03)**：
   - 当遇到交付物出现内容或版式不符合源文档，且判定根因属于系统通用引擎能力缺失（例如：出现未支持的新大类英译、特殊标签空格模式或新法规要求）时：
     1. **严禁自行在系统代码打局部硬编码特判（绝对严禁编写 `if (model === 'xxx')`）**！
     2. **必须立即执行安全停机（Safe Halt）**，并向主协调 Agent / 用户出具标准格式的《系统底座通用缺陷申报单》（包含源文档事实依据、当前底座缺失点、推荐的通用规则方案及受影响范围）；
     3. 只有在人类用户审阅并明文下达“批准底座升级/修改”指令后，方可由系统治理角色受控启动标准 OpenSpec 立法流程修改系统代码。

## 二、 最高法定不变量与覆写红线 (Supreme Invariants & Red Lines)

### 1. 【一切内容源于源文件全局事实底线公理 (Ground Truth Primacy 100%)】
源文件是唯一的法定事实依据。源文件写什么就填什么，源文件未写的内容绝对严禁凭借模型常识擅自外生臆造！

### 2. 【源文件零外生虚增最高公理 (INV-ZERO-EXOGENOUS)】
- **严禁强塞“象形图：无”与“信号词：无”**：
  * 若源文档中未提及 GHS 象形图或信号词（如非危品，或仅有 H412 慢性水生危害等无指定象形图的物质），交付物**绝对严禁**擅自凭空添加 `GHS象形图：无` 与 `信号词：无`（英文版亦严禁凭空添加 `GHS pictograms: None` 与 `Signal word: None`）；
  * **“没有”就是“没有”，不展示任何象形图与信号词标签行才是唯一忠实表现！** 擅自强塞“无”或“None”同样属于严重的外生凭空捏造与标签污染缺陷；
- **严禁强塞防范说明子标题**：
  * 若源文件防范说明中只有单纯的 P 声明语句，严禁外生增加未经源文档授权的分类小标题（如 `预防措施：`、`废弃处置：`）；
- **英文危险性说明净化**：
  * 非危品英文版严禁残留任何危化品词汇（`assert(!/H412|H315|H332|H317|Category/i.test(enText))`），严禁外生 SCBA 呼吸器长句。

### 3. 【格式服从于原文公理 (Format Follows Source Content Axiom)】
- “基于模板的格式与基于源文件的内容做匹配，格式服从于原文”；
- 若源文件某一节仅有叙述性陈述（例如 Section 11“该产品无可用的毒理学研究”或非危险品免责声明），直接匹配到模板中对应的说明行/导言行插槽，沿用模板既定的字体（宋体/Times New Roman/Arial）、字号（9.5pt/10.5pt）与行距排版；其余无关的空白端点行直接物理剪枝删行，绝不可强塞无关假端点；
- 若源文件包含细分结构化端点（如 LC50/LD50），则对应填入结构化值格插槽；
- 绝对杜绝“为了迁就模板结构而凭空捏造端点”或“为了塞入内容而强行破坏模板几何规范”。

### 4. 【底模值格前置强制清零机制 (Pre-write Value Clearing Invariant)】
- 官方底模（尤其英文模板）内可能存在历史样例残留（如二乙二醇单丁醚、3306 mg/kg 等示范数据）；
- **装载模板后的第一动作**：调用 `msds_execute_editor_ops` 的 `clearTemplate` 或 `clearSectionValues` 原语，将所有待编辑值格彻底清空，确保底模处于 100% 纯净的空白插槽状态，再装配新数据，杜绝一切脏数据污染。

### 5. 【模板标签物理剪枝与唯一父级题头免剪枝白名单公理 (Physical Pruning & Skeleton Whitelist)】
严格贯彻执行**【普通叶子标签 vs 唯一父级分类题头标签】**二分法判定：
- **普通叶子标签**：
  * 无下属细分参数的独立数据槽位（如 10.2 危险分解产物、9.x 理化特性单项）。若源文档无对应值且非法定必填，必须剪枝整行删除（`deleteRow`）！严禁留空标签开天窗！
- **🚨 唯一父级分类题头免剪枝白名单 (INV-PRUNE-01)**：
  * 在表格中起分类聚合、统领下属细分参数的标签（如 Section 8.1 的 `手部防护：` / `Hand protection:` 统领下属手套材料规格行；`8.1  暴露控制：`；Section 1 的 `1.1  产品名称：` 等）；
  * **核心法则是【父级标签留空一般允许不删行隐藏】**！当源文件无独立一句话通用陈述时，其值格法定允许保持纯净空白，绝对不可整行删除（严禁 `deleteRow`）；保留加粗标签，值格纯净空白 `""`；
- **🚨 模板受控建议行免剪枝特例 (INV-S8-02)**：
  * Section 8.1 的 `建议：` / `Recommendation:` 属于模板受控建议行（OW-134），源文档有建议（如“污染的手套应废弃。”）必须填入，无源建议时保留标签、清空值格，绝对不可剪枝删行；
  * 无接触限值时，中英表格严格同构收敛为标准的 12 行。
- **🚨 Section 9 理化特性源文件底线保留准则 (INV-S9-01)**：
  * 只要源文档存在该物理属性行，且原文对应值不是空值（即使文本为“无数据”、“无可用数据”、“不适用”、“未提供”、“未测定”、“No data available.”、“Not applicable”等），**必须 100% 完整保留**！严禁机械删除有源支撑的“无数据”行。

### 6. 【表格值格粗细隔离规范 (Value Cell Weight Isolation Invariant)】
- 表格左侧属性标签统一加粗（10.5pt Bold）；
- **右侧值格（Cell 1）必须强制保持常规字重（10.5pt Regular, `b:false`）**，严禁单元格正文被全列加粗！实现“标签粗、内容细”的标准视觉规范。

### 7. 【标点符号纯度与中西文严格隔离公理 (Punctuation Purity Axiom)】
- **中文交付物**：
  * 所有表格标签冒号及正文子标题冒号统一为全角中文冒号 `：`（U+FF1A）；
  * 陈述句段落末尾规范闭合全角中文句号 `。`（U+3002）；
  * 参数数值与单位间严禁残留游离半角句点（规范为：`厚度≧0.4mm；穿透时间≧480min`）；
  * 名词性标签冒号后严禁添加多余句号（如“外观：”后绝不能出现“：。”）。
- **英文交付物**：
  * 页眉版本号（`Version: V1.0`）、页脚及所有标签冒号统一为西文半角冒号加单空格 `: `；
  * 句子末尾使用标准半角句点 `.`，绝不允许残留中文全角标点；
  * **度数符号规范**：绝对严禁使用汉字库全角符号 `℃`（U+2103），必须统一转换为西文国际标准 `°C`（U+00B0 + C）；
  * **词法完整性**：严禁词内断裂空格（如 `equ ipment` 必须规范为 `equipment`）。
- **Section 13 废弃处置段落对齐**：
  * 废弃处置叙述性长文本统一规范为靠左对齐（`w:jc w:val="left"`），严禁使用两端分散对齐（`both`）导致字符异常横向拉伸！

### 8. 【化工专业定性公理 (Chemical Domain Qualitative Invariant)】
- 固化剂（改性脂肪胺固化剂等）与乳液/分散体在涂料化学原理上完全对立；
- 生成英文品名时，必须建立严格优先级，优先匹配 `/固化剂/`、`/curing agent/`、`/hardener/`，绝对严禁将固化剂误译为乳液（`emulsion`），必须输出 `Waterborne epoxy curing agent`。

### 9. 【全局表格外实内虚边框公理 (Unified Table Border Invariant)】
- 全局表格边框铁律：各 section 表格外框用实线 (`single`)，内框用统一虚线 (`dotted`)；
- 动态增减行（如 Section 3 组分增行、Section 8 控制参数增行等）后，必须严格维持顶底及左右外框实线、内部虚线。

### 10. 【双主体预设隔离派生与时间戳毫秒级同步】
- 广州冠志与英德国彩双主体预设隔离派生，抬头、落款（地址、电话、应急电话）精准绑定；
- 4 份 DOCX 与 4 份 PDF 必须全量联动重新生成，时间戳差严格 $< 10\text{s}$（目标 $0\text{s}$），严禁交付滞后的旧版 PDF。

## 四、 MSDS-Engine 官方 MCP 工具链调用指南

### 1. `msds_recognize_source`
- **功能**：零损耗识别源 DOCX 文件的 16 章节全部化学事实与理化指标。
- **调用参数**：
  ```json
  {
    "sourceFilePath": "F:/App Location/.../EC-1804 msds_CN 冠志(1)_源文件留存.docx"
  }
  ```
- **关键输出**：返回包含 16 章节未分类事实、CAS 组分列表、理化数值对象、GHS 分类与防范说明的结构化事实对象。

### 2. `msds_extract_section_facts`
- **功能**：细粒度下钻提取指定章节（1~16）的详细事实与网格排版形态。
- **调用参数**：
  ```json
  {
    "sourceFilePath": "F:/App Location/.../源文件.docx",
    "sectionNumber": 8
  }
  ```

### 3. `msds_get_template_schema` & `msds_peek_cell_or_row`
- **功能**：透视模板的网格架构、行列数、单元格属性与文本内容。
- **调用参数**：
  ```json
  {
    "templateKey": "guanzhi_cn",
    "sectionNumber": 8,
    "rowIndex": 3,
    "cellIndex": 0
  }
  ```

### 4. `msds_execute_editor_ops`（万能编辑器核心操作通道）
- **功能**：执行一组有序原子操作，完成清零、剪枝、增行、写值与排版。
- **支持的原子原语 (`op`)**：
  * `clearTemplate`: 全模板值格清零（施工第一步必选）；
  * `clearSectionValues`: 指定章节值格清零；
  * `deleteRow`: 物理整行删除（普通叶子标签无值剪枝）；
  * `insertRow`: 动态增行（Section 3 组分增行）；
  * `mergeCells`: 单元格横向合并（`colStart`, `colSpan`）；
  * `deleteColumn`: 删列；
  * `writeCell`: 写入单元格（支持 `text`, `runs`, 粗细隔离）；
  * `writeRichText`: 写入富文本或化学式下标；
  * `formatLaserTabs`: 激光垂线对齐；
  * `applyPreset`: 应用公司预设（`guanzhi` / `guocai`）；
  * `checkpoint` / `rollback`: 事务检查点与回滚。
- **调用参数示例**：
  ```json
  {
    "templateKey": "guanzhi_cn",
    "outputPath": "F:/.../产出_CN_冠志.docx",
    "operations": [
      { "op": "clearTemplate" },
      { "op": "writeCell", "sectionNumber": 1, "rowIndex": 1, "cellIndex": 1, "text": "EC-1804 水性环氧固化剂" },
      { "op": "deleteRow", "sectionNumber": 10, "rowIndex": 2 }
    ]
  }
  ```

### 5. `msds_batch_export_eight`
- **功能**：驱动 MSDS-Engine 批量受控流水线，导出 4 DOCX + 4 PDF 交付物。
- **调用参数**：
  ```json
  {
    "modelCode": "EC-1804",
    "sourceFilePath": "F:/App Location/.../源文件.docx",
    "targetDir": "F:/App Location/.../EC-1804"
  }
  ```

### 6. `msds_compare_source_with_output`
