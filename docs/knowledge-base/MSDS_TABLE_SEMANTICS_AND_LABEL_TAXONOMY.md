## (MSDS Table Semantics and Label Taxonomy Manual)

> **版本**：v1.0.0-ENTERPRISE  
> **体系归属**：OrbitStack (Ps-openspec) 轨道工程体系 · MSDS-Studio 工业级项目开发知识库  
> **法定作用域**：全系统源文件识别（Stage 2）、Context 1/Context 2 事实治理、模板覆写排版及自动化审计套件之最高法定语义字典。

---

## 一、 规范总纲与立法背景

在 MSDS/SDS 的结构化工程解析与文档自动化生产中，文档由 16 个法定章节与复杂异构表格组成。历史上曾多次出现因词法判定过于机械（如单纯凭借“是否加粗”或“末尾是否带冒号”）而导致的系统性顽疾：
1. **伪标签导致值格被抽空**：将长句警告（如“在着火或爆炸情况下，不要吸进烟尘。”）或技术说明（如“根据EC指令无可用的接触限值信息”）因加粗而误判为标签，导致下游数据插槽脱靶；
2. **分类层级扁平化与混淆**：将统领下属多行规格的分类题头（如 Section 8 的 `手部防护：`）与具体细分参数（如 `手套材料：`、`手套厚度：`）统一笼统标记为“标签”，导致排版垂直对齐混乱、父子从属关系断裂；
3. **剪枝误判与开天窗冲突**：误将起分类聚合作用的父级标签当成普通叶子标签，因其右侧无通用一句话陈述而错误删行，引发下级子行错位。

为彻底根治上述病灶，特立本手册作为全系统统一的**语义分类最高宪法**，确保任何流水线、CLI 脚本与智能体均遵循绝对同一的判断标准。

## 二、 核心语义分类角色体系 (The 8 Semantic Categories)

系统将源文档表格中的所有行与单元格划分为以下 8 大法定语义属性类别，在 Context 1 表格中以纯净关键词严格标识：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        MSDS 表格语义分类树 (Taxonomy Tree)             │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 章节标题 (SECTION_HEADER)  ─── 16个法定一级大标题 (v1.容差)           │
│ 2. 序号标签 (SEQ_LABEL)       ─── 带明确点分数字编号的属性题头 (1.1, 8.1) │
│ 3. 父级标签 (PARENT_LABEL)    ─── 分类聚合统领题头 (手部防护/建议/白名单) │
│ 4. 子标签   (CHILD_LABEL)     ─── 具体叶子属性字段 (中文名称/手套材料)     │
│ 5. 数据值   (VALUE)           ─── 具体技术数据/实验结论/常规体与加粗值     │
│ 6. 说明行   (EXPLANATION)     ─── 指导叙述长句/前言引言/免责通栏/续行说明 │
│ 7. 数据值行 (DATA_ROW)        ─── 纯清单条目 (法规列表/多列参数条目)       │
│ 8. 表头/组分 (TABLE_HEADER/COMPONENT_DATA) ─── 成分表/暴露限值专用多列 │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 章节标题 (Section Header - `章节标题`)
- **定义**：16 个法定一级大章节题头，统领整张表格或大区块，通常为单单元格通栏排版，字号为小四加粗（12pt Bold）。
- **容差规则**：自动兼容并清洗历史杂质前缀（如 `v1.`、`V1.`、`  1.`），清洗后标准格式为 `${secNum}.${title}`。
- **典型示例**：`1.物料及供应商标识`、`2.危险性概述`、`8.接触控制/个人防护`、`16.其他信息`。

### 2. 序号标签 (Sequenced Label - `序号标签`)
- **定义**：带有明确小节/层级点分数字编号（如 `1.1`、`1.2`、`4.2`、`8.1`、`9.1`、`11.2` 等）的行级属性题头。
- **词法特征**：行首或单元格起始包含 `/^\d+\.\d+/` 正则模式，通常末尾带冒号。
- **典型示例**：`1.1产品名称：`、`4.2误服：`、`5.3物质或混合物的特殊危害：`、`8.1控制参数`、`9.1外观与性状：`、`11.2主要皮肤刺激性：`。

### 3. 父级标签 (Parent Label - `父级标签`)
- **定义**：在表格中起**分类聚合、统领下属多行细分属性**的顶层无序号题头（或特例分类题头）。
- **核心法则 (INV-PRUNE-01)**：【父级标签留空一般允许不删行隐藏】——当源文件无独立一句话通用陈述时，允许加粗保留标签、右侧值格保持纯净空白，绝对严禁物理删行（防下属规格错位挂靠），且严禁误报为开天窗！
- **词法特征**：
  1. 命中白名单：`/(?:手部防护|建议|供应商信息|分类题头|分类标准|防护指南|通用要求)[：:]?$/`；
  2. 结构特征：在双列行中，左列包含简短标签，但右列为空（`!c1Text`），且并非段落前言说明；
  3. 法定特例：Section 8 的 `手部防护：` 与 `建议：` 强制归类为 `父级标签`。
- **典型示例**：`手部防护：`（统领手套材料、手套厚度、渗透时间等）、`供应商信息：`（统领名称、地址、电话、传真）。

### 4. 子标签 (Child Label - `子标签`)
- **定义**：无独立数字编号、归属于小节或父级标签之下的叶子级具体属性字段。
- **词法特征**：
  1. 字数短小：中文 $\le 15$ 字符，英文 $\le 60$ 字符；
  2. 格式规范：末尾带冒号（`：` 或 `:`），且加粗排版；
  3. 结构特征：在双列行中位于左列，右列直连具体数据值。
- **排版对齐法则**：在垂直方向上按**二级缩进基准线**垂直共线对齐，与父级标签形成明确层级对比。
- **典型示例**：`中文名称：`、`化学品分类：`、`供应商名称：`、`电话：`、`传真：`、`GHS分类：`、`GHS象形图：`、`呼吸系统防护：`、`眼睛防护：`、`身体防护：`、`手套材料：`、`手套厚度：`、`渗透时间：`、`处理方法：`。

### 5. 数据值 / 加粗值 (Value - `数据值`)
- **定义**：承载具体技术数据、实验结论、参数指标、产品名称或事实描述的实体内容。
- **词法特征**：
  1. 位于表格右侧值列（`col > 0`），或位于键值对拆分后的右侧部分；
  2. 即使源文档中文字被加粗，若其属于技术结论且字符数超出阈值或无冒号，仍判定为值；
  3. 对应底层样式应保持常规字重（10.5pt Regular / `sz="21"`），严禁因加粗误判导致整行全黑。
- **典型示例**：`PA-3612`、`水性丙烯酸共聚物乳液`、`商业机密`、`禁止催吐，须就医。`、`无刺激`、`非危险货物`、`根据GHS不属于危险物`。

### 6. 说明行 (Explanation / Preamble Row - `说明行`)
- **定义**：非“键值对”结构的指导性叙述长句、前言引导语、免责声明、法规适用性阐述或续行说明。
- **词法特征**：
  1. 结构特征：单单元格通栏，或双列行中左列为空（`!c0Text && c1Text`），或右列为空的前置引导语；
  2. 句式特征：常包含引导词或长句陈述（“根据...”、“在...情况下”、“该产品无可用的...”、“符合下列法规要求：”、“其它的规定：”）；
  3. 冒号解耦：引导语即使末尾带有中文冒号 `：`，若右侧无值，仍判定为说明行而非标签。
- **典型示例**：
  - `在着火或爆炸情况下，不要吸进烟尘。`（Section 5 续行叙述）
  - `根据EC指令2006/121/EG,无可用的接触限值信息`（Section 8 接触限值说明）
  - `类似产品的风险评估数据：`（Section 11 毒理评估引言）
  - `符合下列法规要求：` / `其它的规定：`（Section 15 法规前言引导语）
  - `物质或混合物分类`（Section 2 子题头）

### 7. 数据值行 (Data Value Row - `数据值`)
- **定义**：纯粹展示清单条目（如法规清单）或无标签修饰的技术参数列表行。
- **典型示例**：Section 15 中的法规清单：
  - `危险化学品安全管理条例，国务院令591号`
  - `GB/T 16483 化学品安全技术说明书内容和项目顺序`
  - `GB 13690 化学品分类和危险性公示通则`

### 8. 表头与组分数据 (Table Header & Component Data - `表头` / `组分数据`)
- **定义**：专用于 Section 3 成分表与 Section 8 接触限值表的多列网格。
- **典型示例**：
  - `表头`：`化学品名称 | CAS编号 | %（w/w）`
  - `组分数据`：`丙烯酸树脂 | CAS: 商业机密 | 浓度: 43-45`

## 三、 6 大硬阻断词法边界与上下文判定公理

为保证自动化算法与人工认知 100% 吻合，全系统执行以下 6 大硬阻断公理：

### 公理 1：10 字符安全字数阈值法则 (Length Safety Axiom)
- **法则**：标签的核心特征是字数简短。
- **判据**：对于加粗文本，若字符数超过 **10 个中文字符**（或 40 个英文字符），且末尾**不带冒号**（且非 Section 大标题），**一律降级判定为值（Value）或说明行**，严禁误判为标签导致值格被抽空！

### 公理 2：同行前置标签与列位置感知法则 (Col > 0 Context Axiom)
- **法则**：行内后续单元格属于数据值空间。
- **判据**：若单元格位于非首列（`col > 0`），或者同一行左侧已经存在父级标签/标签，后续单元格即使含有加粗文本，也一律视为**加粗数据值（Bold Value）**，严禁误切为新标签。

### 公理 3：唯一父级分类题头免剪枝白名单法则 (INV-PRUNE-01 Parent Retention Axiom)
- **法则**：分类题头统领下属细分参数，不依赖自身右侧是否有值。
- **判据**：对于命中父级标签白名单（如 Section 8 `手部防护：`、`建议：`，Section 1 `供应商信息：`）的行，当源文件无通用一句话陈述时，其值格法定允许保持纯净空白，绝对严禁整行删除（严禁 `deleteRow`），严禁误判为开天窗。

### 公理 4：前置引导语与冒号解耦法则 (Preamble Colon Decoupling Axiom)
- **法则**：段落引导语末尾的冒号不等于键值对。
- **判据**：命中关键词（`/风险评估|其它规定|法规要求|免责声明|适用范围/`）的文本行，即使末尾带有中文冒号 `：`，若其右侧列为空，属于段落引言，**必须判定为 `说明行`**，绝不可当成键值对标签。

### 公理 5：左列空白续行保护法则 (Left-Empty Continuation Axiom)
- **法则**：多行长文本跨行时的排版保护。
- **判据**：若双列行中左列为空字符串（`!c0Text`），右列包含文字，判定为上一项的**续行说明（`说明行`）**，绝不可因字数或样式判定将右列误当标签。

### 公理 6：纯标点符号与孤立空白物理剥离法则 (Punctuation Stripping Axiom)
- **法则**：标点符号不具备语义标签属性。
- **判据**：过滤纯标点（如单独加粗的 `。`、`-`、`:`），严禁识别为独立标签。

## 四、 真实工程典型案例对照表 (Case Study)

| 章节位置 | 原始文本示例 | 归属语义分类 | 归属判定依据 |
| :--- | :--- | :---: | :--- |
| **Section 1 行 0** | `1.物料及供应商标识` (清洗自 `v1.`) | `章节标题` | 命中一级章节序号与关键词，通栏排版，小四加粗 |
| **Section 1 行 1** | `1.1产品名称：` | `序号标签` | 包含点分小节序号 `1.1`，带冒号 |
| **Section 1 行 2** | `中文名称：` | `子标签` | 依附于 1.1 的叶子属性，无序号，字数 $\le 15$，带冒号 |
| **Section 1 行 5** | `1.3供应商信息：` | `序号标签` | 包含点分小节序号 `1.3`，统领下属供应商详情 |
| **Section 1 行 6** | `供应商名称：` | `子标签` | 依附于 1.3 的细分属性字段 |
| **Section 2 行 1** | `物质或混合物分类` | `说明行` | Section 2 子题头/引言说明，无冒号，通栏 |
| **Section 2 行 2** | `GHS分类：` | `子标签` | 穿透解构出的叶子属性标签，右侧直连数据值 |
| **Section 5 行 4** | `在着火或爆炸情况下，不要吸进烟尘。` | `说明行` | 左列为空，右列为烟尘长句警告，续行说明 |
| **Section 8 行 1** | `8.1控制参数` | `序号标签` | 点分编号题头，小节入口 |
| **Section 8 行 4** | `手部防护：` | `父级标签` | 命中 INV-PRUNE-01 白名单，统领下属手套材料等规格行 |
| **Section 8 行 5** | `手套材料：` | `子标签` | 依附于手部防护的细分参数字段 |
| **Section 11 行 2** | `类似产品的风险评估数据：` | `说明行` | 命中前言引导语，右列为空，冒号解耦为说明行 |

| **Section 15 行 4** | `危险化学品安全管理条例，国务院令591号` | `数据值` | 纯法规条目清单行，无键值对 |
