# MSDS 覆写约束 · 提炼版（全局 + 局部）

> 以 v3.29 为准，合并 v1.0 / v2.9 / v3.15 / v3.28 去重；原 114 条细则见 `MSDS覆写约束_整合版.md`，5 份底稿见 `constraints_work/*.json`。
> 读法：A 部分是任何一节都必须遵守的；B 部分是各节的特殊追加，只会收紧、不会放宽 A；C 部分是版本间打架点，已标“以谁为准”。

## A 全局覆写限制（S1–S16 通用）

### A1 权威归属与血缘（谁说了算）
- G-01 模板管结构表现、源文件管产品事实，禁止互换；禁止把模板示例与来源产品取并集，参考 MSDS 只学排版不取数。
- G-02 一律从权威模板字节拷贝克隆后原位改；禁止空白文档/重建表组；禁止由渲染 CN 派生 EN；CN 克隆 CN 模板、EN 克隆 EN 模板，EN 不得加 CN 行凑数。
- G-03 无明确新批准模板就用内置基线；新批准模板立即取代旧基线并同步更新文件名/SHA/快照；历史模板、旧快照、历史输出一律不得当生产母版。
- G-04 克隆前验模板 SHA 钉死值，变化整单阻断；终稿须能证明源自钉死快照，否则不交付。
- G-05 16 表顺序不可增删；CN/EN 物理行数不同是允许的（CN `[10,16,6,6,5,4,3,16,24,6,18,6,3,5,9,2]`、EN `[9,16,6,6,5,4,3,16,24,6,18,6,3,5,9,2]`），但语义规则一致。
- G-06 模板示例（PEA-4139、示例成分/危害/毒理/生态、S8.2 两行示例 OEL）出厂前必须清除或换成源实证行；`source_grounding` 会逐值查源，漏清即阻断。

### A2 能改什么、不能碰什么（突变边界）
- G-07 Agent 只允许 4 件事（runtime 执行）：写源实证值进既有值格；源缺席时清空值格；删整行仅限专用空/不支持行；仅 S3/S8.2/S9/S15 可插完整源实证样式行。
- G-08 序号与标签措辞锁定；唯二例外：删行后数字前缀连续化、S9 源实证测试条件限定词。其他一字不改。
- G-09 加粗标签硬锁（原文/标点/编号/`w:rPr`/`w:pPr`/格边框合并列宽行高，原 XML 复用）；非加粗路由前缀/子标签同样硬锁：S2.8 五前缀、S11.1/11.7 中间子标签、三列行前两列、S8.2 非值列。
- G-10 多列行只写末端值格：两列 S2.8 = 锁定前缀 + 值尾（清空留前缀）；S11 三列行只写末格；三列永不压两列，S8.2 四列永不压散文。
- G-11 禁止 `paragraph.text=` / `cell.text=`、清空 run 塞 run0、重建标签、空格制表假对齐、跨段拷样式、为凑源顺序删行；禁全局字体间距缩进归一化（EN 仅允许同模板值格重断）。
- G-12 表可跨页，存活行 `cantSplit`/重复表头与新鲜克隆一致；禁人工分页；每节走 `section_overwrite_rules.py` 登记的 writer，位置型 payload、缺/重/歧义目标槽直接阻断。

### A3 值排版（一次写对）
- G-13 非空值 run 显式字体字号：CN 宋体 12pt、EN Times 12pt，值非加粗、格垂直居中、段左对齐（S3 三数据格横竖居中例外）；writer 拥有整格时单行一 run、无悬空空段。
- G-14 紧凑版式：禁空段/空 run/制表/重复空格/尾空格/对齐换行/固定行高留白；一语义值 normally 一段；有义源换行在值格内作 Word 换行，`通风/排气` 等紧凑式原样，合成 ` / ` 先变语义换行，纯 `/` 行阻断。

### A4 有无数据怎么办（缺失抑制）
- G-15 永不臆造 CAS/浓度/GHS/H-P/毒理生态/限值/UN/法规/官方法定英文名。
- G-16 无对应值整项不显示：删完整项，不留空标签空行占位符；删除用最小安全边界（整行恰一项才删整行），删后四变体项集一致。
- G-17 缺失默认 `无数据`/`No data available`、禁加“源文件未提供”话术；但 `不适用` 与实质否定（非危险品/无危险反应/初沸点以下无闪点/未满足分类标准/无刺激）有源就保留。
- G-18 S11/S12 节级说明句（`该产品无可用的毒理学研究。`）有支撑数据时作无编号说明行保留；端点全无则只留源说明行并删模板端点示例行，其后禁跟索数话术。

### A5 编号（先删后排）
- G-19 全部删抑制定稿后再按节连续 `N.1,N.2…`，只改数字前缀；子行/H-P 行不占号，同主项子行可重号（尤其 S11 多路由）；S11/S12 保源端点号有序不重现，不对 11.7 重排；S9 删纯缺失行后连续且终面无纯缺失行。

### A6 身份与一致（写一次、对四份）
- G-20 题头=型号；CN `产品名称` 留空；CN `中文名称`=中文名+1空格+型号；EN 名须已评审（禁现编、禁窄化）；页脚=`<MODEL>-MSDS`。
- G-21 同语言冠志/国彩只差 5 项（名称/地址/电话/传真/页脚公司），其余一字不同即阻断；先一语言建一次内容再套覆盖。
- G-22 四份同源一事实模型；禁 CN→EN 翻译派生；跨语言只差措辞不差事实（数字/限定/路由/方法/CAS/浓度/分类等价，不升级证据）。

### A7 门禁（不通过就不发）
- G-23 审计非零即阻断：缺失压制、空值行、S9省略重排、编号、标签几何、空白、S2 H-P、S11结构、源覆盖台账追溯、英文术语、双语等价、白名单差、身份；每 DOCX 全页 100% 目检。
- G-24 克隆前双门：`agent_execution` 评审门 + `source_coverage/fact_ledger/source_mapping/output_traceability/section2_routing` 五记录门；`source_absent`≠`source_unreadable`，仅评审缺席决可空行动。
- G-25 机械只做 IO/克隆/值写/抑制重排/插图/戳记/审计，判断（S2定级、S11槽映射、H-P措辞、EN翻译、致敏拆分、缺失vs不适用、覆盖、等价、目检）逐项 `AGENT_DECISION` 留源据；禁批量正则代判。
- G-26 源发现禁旁路：正式输出永不作源，输出缓存目录禁作源址，PDF 禁作源；`build_matrix` 验 SHA/型号/16节/双语/15槽S2/评审映射后才克隆。

## B 局部覆写限制（各节追加，收紧 A）

- L-S2（G-16/G-19 之上）：仅源实证分类标签；H/EUH 一码一行、P 一码一行保序；P 四组标题是值格内结构非新标签，空组压制；源2.2注意只进模板2.3槽（特殊物质+阈值，限值粘解释行）；信号词仅收 危险/警告/无信号词/无/None/Not applicable；S2.8 五路由独立事实，总论禁抄入路由，缺席路由留空删行不许后值前移，H 逐路由独立比对；有图原图入象形格、无图仅显式分类解析；写完删纯无数据行，`2.3其他危险` 源显式（含无适用资料）保留参排；应急概述禁拼装、一事实默认独占一目标。
- L-S3：名/CAS/含量原样（含商业机密），一组分一行，多则克隆样式行；三格全写横竖居中；组分 GHS 为路由证据禁抄 S2.2/2.3。
- L-S4–S7/S10/S13/S14：按功能/等义映射，去换行伪影，文案紧凑；禁拿模板示例加建议；S10 缺“避免条件/禁配物”即消失；S13 说明并单格注槽；S14 四运输独立，仅源支撑用 ADR/RID/IMDG/IATA，UN/名/类/包装/特殊各一逻辑行。
- L-S8（易错：源8.1→模板8.2，源8.2→模板8.1）：PPE 按呼吸/手/手套/FKM/IIR/NBR/建议/眼/身进既有标签，`EN 374` 原样，FKM/IIR/NBR 行拆标签+值禁空；`建议` 标签锁值格源门控；S8.2 四列（父行+表头物质/依据/类型/数值锁死）仅源实证数据行可写，无源删整块禁合成无数据。
- L-S9（唯一标签例外）：一属性一行，禁并（水溶粘度、离子性其他信息），NCO 独立；仅源明确测试条件可进标签且不改属性名格式与 `9.n` 五宽槽；同属性多条件分行，无行可表则插样式行或阻断禁合并；发布前逐属性比对，终面无纯缺失行。
- L-S11（最高优先）：禁标点切分，按端点→研究块→字段→值；`Species: Rabbit` 不拆；Buehler/LLNA、Ames/染色体畸变各自分研究；口/皮/吸入不并；先对齐模板骨架再判删，11.1/11.7 按子标签配，未中阻断；三列行只写末格；11.7 生育/致畸/体外遗传毒性仅同名源字段可填；只写明示端点值物种结果分类方法证据限定；`主要粘膜刺激性` 进 11.3 不进 11.10；经皮吸入保源评估原话禁编 LD50/LC50；去重仅去模板已拥有的题头（含 11.2 `皮肤-`、11.3 `眼-`），余下逐字留，此规则禁泛化。
- L-S12：生态毒性必进 12.1，模板前导说明注无源即删；注保留单格值槽。
- L-S15/S16：S15 只留源实证法规删尾空行保源序，加粗 `其它的规定/符合下列法规要求` 是锁死题头非值槽；禁静默现代化法规声明文本；S16 无行重建。

## C 矛盾清单（以 v3.29 为准，已裁决）

- C-01 缺失到底写不写 `无数据`：v2.9 R4 说占位符一律整项省略、终面不见；v3.29 说客户面默认 `无数据` + S11.7/S2.3 等端点例外。裁决：**以 v3.29 为准**——终面允许显式端点态的 `无数据`（S2.3 留源话、S11.7 仅源显式才写），其余缺席模板字段直接抑制；S9 终面仍不见纯缺失行（沿 v2.9）。
- C-02 S9 标签到底能不能改：全局说标签一字不改，S9 说测试条件可进标签。裁决：**唯一例外是 S9**，且仅加源实证限定词，不改属性名、不改前缀槽与格式。
- C-03 S8 方向反直觉：源 8.1→模板 8.2、源 8.2→模板 8.1。裁决：**按语义走**，禁按行位拷贝，写错即污染阻断。
- C-04 模板示例算不算数：旧版“模板仅示意”与新版“未清空示例变事实即阻断”看似重复。裁决：**合并为一条**（G-06），漏清按事实污染阻断。
- C-05 S11 去重范围：v3.27.13 曾全局去重，v3.27.14 收敛到 S11。裁决：**仅 S11** 去模板已拥题头，普通节值头相似也不删。
- C-06 行数基线漂移：v2.9 是 S11 六行/S2 十六行旧几何，现行 CN/EN 行数已变。裁决：**以 v3.29 行数基线为准**（G-05），旧几何只作回归史。
- C-07 交付数：v2.9 双公司、v1.0/v3.29 八交付（4 DOCX+4 PDF）。裁决：**默认八交付**，用户显式要少才少。
