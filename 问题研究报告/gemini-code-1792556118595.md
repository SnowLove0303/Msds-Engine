# BL-8129A MSDS 中英文格式与“标签-值”全量核对报告（Section 2 - 16）

## 一、 核心结论与版本演进总结
1. **中文版两个版本的关系**：
   - **`BL-8129A msds_CN 冠志_2.docx`（简称：中文版_2）**[cite: 3]：属于早期无子序号版本（多数标签无 `2.1`、`4.1` 等编号，且第3节成分混在同一单元格内，第8节顺序为 `8.1控制参数`、`8.2暴露控制`）[cite: 3]。
   - **`BL-8129A msds_CN 冠志.pdf` / 首轮中文 docx（简称：中文正式版）**[cite: 1, 4, 5, 6, 7, 8]：属于规范化排版后的版本，统一补齐了 `2.1`~`14.4` 的子序号（PDF版连 `3.1/3.2`、`7.1/7.2` 也已补齐），并将第3节拆分为4行独立行，将第8节调整为与英文版完全一致的 `8.1暴露控制`、`8.2工程控制` 5列跨度表格[cite: 1, 2, 4, 5, 6, 7, 8]。
2. **中英文对照核心问题（5大严重不匹配处）**：
   - **Section 2（危险性概述）**：英文版多出1行（共4行），且值完全不符（中文为非危险品，英文写成了H412水生慢性危害3类，并出现“丙二醇甲醚”）[cite: 1, 2, 3, 4]。
   - **Section 5（消防措施 5.2）**：英文版 `5.2 Unsuitable extinguishing agents` 的值发生复制粘贴错误，直接照搬了 `5.1` 的值[cite: 2]。
   - **Section 9（理化特性）**：表格格式完全对齐，但 **9.3 pH值、9.4 离子性、9.11 密度、9.17 动力粘度、9.18 固体含量** 共5项核心指标数值完全对不上（英文版疑似套用了环氧乳液的数据未修改）[cite: 1, 2, 3, 6, 7]。
   - **Section 11（毒性资料）**：英文版与《中文版_2》同样保留了 `Risk assessment data for similar products:`（类似产品的风险评估数据）这一行（中文正式版删去了该行），但英文版在 `11.2-11.4` 的值中额外增加了实验动物物种（Rabbit / Guinea pig）[cite: 1, 2, 3, 7]。
   - **Section 15（法规信息）**：英文版底部5条中国法规名称未翻译为英文，且法规版本号（591号令、GB 30000.2-29）与中文版（344号令、GB 20576-20598）不一致，《中文版_2》还漏掉了最后一条 `GB 15258`[cite: 1, 2, 3, 8]。
