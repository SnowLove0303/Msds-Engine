# CN 冠志 MSDS 模板覆写快速编辑器

双击 `启动编辑器.bat`，默认会打开：

`F:\App Location\Guanzhi Tong\Skill\MSDS Skill\模板\正式模板_MSDS_CN_冠志(1).docx`

窗口顶部的“常用模板”下拉框内置：

- CN 冠志：`正式模板_MSDS_CN_冠志(1).docx`
- EN 冠志：`正式模板_MSDS_EN_冠志(1).docx`

选择后点击“载入”即可。两套模板都只读打开，程序会先创建编辑工作副本。

完整模板资源实际随程序放在：`内嵌模板` 目录。不是只保存表格框架，DOCX 中原有的序号、标签、子标签、值、说明行、表格边框、合并单元格和文字格式都随模板资源一起保留。

也可以把任意其他 `.docx` 拖到 `启动编辑器.bat` 上，或启动后点击“打开模板”。导入后程序会把源文件复制到临时工作目录，所有编辑、序号重排和导出都基于副本；源文件不会被直接写入。
如果直接使用 `python msds_template_editor.py`，程序检测到当前 Python 没有 Tkinter 时会自动清理 LibreOffice 注入的 Python 环境变量，再切换到 Windows Python Launcher 的 `py -3.12`。

如果要把已有 MSDS 的内容套入正式 CN 模板，可使用 `standardize_from_template.py`。它以正式模板为表格和格式母版，按章节/标签把源文件值填入模板，清空未匹配的模板示例值，并且只读源文件：

```powershell
py -3.12 standardize_from_template.py source.docx 正式模板_MSDS_CN_冠志(1).docx output.docx
```

## 使用约束

- 序号始终只读；加粗标签和子标签默认只读。特殊情况下可打开顶部“特殊情况：允许修改标签”开关，确认提示后修改标签文字本身；该开关不会解锁序号、字体、加粗、段落、表格或页面格式。
- 编辑器按原 DOCX 的行列结构展示每个 Section；三列的“标签—子标签—值”不会被压成普通字段列表。
- 单行单列且没有加粗内容的行会标记为“说明行 · 单列值”。
- 会识别表格中的序号、标签、子标签、值和说明行；短的冒号结尾标签即使没有加粗，也会作为标签候选显示。
- 导出使用“另存为”，默认文件名为 `原文件名_编辑后.docx`，不会自动覆盖源模板。
- “在此行后新增”复制当前行的 Word 结构与格式，并清空非加粗值。
- “删除此行”只对包含可编辑值的非首行开放；标题、表头和结构行不会删除。
- 新增/删除行后，导出前会自动重排同一章节中连续的可见编号，重复的编号组会保持重复。

## 运行环境

Python 3.10+、Tkinter 和 `python-docx`。本机推荐使用 `py -3.12`（默认 LibreOffice Python 不含 Tkinter）；若在另一台机器运行，请安装：

```powershell
python -m pip install python-docx
```

## 保护边界

编辑器不重建表格，不改写序号、加粗角色、段落样式、字体属性、边框、合并单元格、列宽、行间距、字间距、居中方式和页面设置；默认只修改未加粗值和说明行的文字内容。只有在显式打开标签编辑开关后，才允许修改标签文字本身，标签原有加粗和所有格式仍保持不变。异常导出不会覆盖源模板。

运行核心自检：

```powershell
python test_editor.py
```
