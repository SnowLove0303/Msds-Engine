# MSDS 表格检索

在 Windows 上用 Python 启动：

```powershell
cd "F:\App Location\Guanzhi Tong\Skill\MSDS Skill\检索功能"
py -m pip install -r requirements.txt
py msds_table_search.py
```

点击“导入 DOC / DOCX / PDF”选择 MSDS。左侧按章节、表格和页码列出内容；输入关键词可筛选命中的条目。右侧默认显示“原版页面”，“结构化表格”页签检查行列和单元格，“格式与表格属性”页签查看段落、文本片段、字段候选和表格属性。点击“导出识别 JSON”可保存 Agent 可读取的完整结果。

- DOCX 识别 JSON 使用 `schema_version: 1.0`，逐表提供行列、合并关系、单元格段落/文本片段、直接格式属性、单元格/行/表格属性、字段候选及其来源坐标。字段候选只表示“加粗或冒号标签 + 相邻值”等结构证据，不代替原始单元格文本；每个候选会标注识别方法和源单元格坐标。完整 Word XML（正文、样式、编号、页眉页脚等可读取部件）同时保存在 `source_ooxml`，避免标准化解析未覆盖的 Word 标签被静默丢弃；`recognition_warnings` 和 `coverage` 报告未标准化元素及表格计数差异。
- DOCX 的文字格式段包括源中显式保存的字体、字号、加粗/斜体、颜色、段落对齐/间距/缩进及各级 OOXML 直接属性；表格属性包含网格宽度、行列索引、合并关系、行高、单元格尺寸、边框、底纹和边距。原版页面预览用于确认继承样式及最终版式。
- 结构化视图按源网格宽度显示表格，行高随实际换行和图片高度自适应；文字运行连续显示，图片按原文顺序内嵌。图片元数据和常见危害代码别名（如 GHS07/感叹号、GHS08/健康危害）可检索。
- Word 文件原版面预览通过 Windows 上的 Microsoft Word/WPS 导出 PDF，再由 PDFium 展示，保留原表格排版、字体和文本格式；DOC 读取与预览都需要 Word/WPS 兼容自动化接口。原件以只读方式处理，临时文件在退出程序时清理。
- PDF 使用 `pdfplumber` 提取每页表格、字词位置、字体名、字号和可检测到的单元格坐标，并直接渲染 PDF 原始页面。PDF 的粗体语义和合并关系可能无法可靠推断，识别结果会明确标记坐标/格式信息的可用范围；未识别成表格的内容仍可从页全文及原版页面查看。
- Word 页眉和页脚统一归入“第 0 部分：页眉 + 页脚”，支持搜索；选择结果会打开原版页面预览。
- 所有读取均在本机完成，程序不会写回或覆盖原文件。
