# Proposal

## Why

用户最新截图纠正了实施范围：白底灰边黑字及去重复包框只用于图一模板编辑器红框内的控件条；图二 DOCX 识别页恢复之前正常 UI。原先全站控件迁移范围已撤销，不能因共享 CSS 把导航、页面主操作、其他页面或文档内容一起改色。

## What Changes

- 图一红框内：基准/预设上下文栏、文件名及模板基准控制条、Section 标题栏、编辑区顶部工具栏、预览顶部模式/缩放工具栏，局部统一白底灰边黑字、尺寸/中线与间距，减少重复说明和框套框。
- 图一红框外：品牌/全局导航、页面标题、右上审计/批注/蓝色导出/预设管理/恢复按钮、章节列表主体与搜索、编辑表格内容、预览文档及下方审计面板保持现有回滚基准外观，不作中性改色或重新分配布局。
- 图二：恢复 DOCX 识别页控件改造前的可见导入区域、标题、按钮和间距。优先核对既有 Git/快照中的组件规则；不能直接恢复整份历史文件。已发现导入标题 rgb(241,247,254) 在浅底上近乎不可见，需恢复浅色模式中可读标题与导入容器。
- 建立仅匹配红框语义区域的 opt-in class/data attribute；禁止修改全局 .button、:root、nav、empty-workspace 或通用 preview 规则实现局部需求。
- 旧轮交互/持久化/导出欠账记录保留，超出本截图范围的全站视觉和布局任务退出此次实施；保留已修好的功能，不借回滚覆盖业务代码。

## Capabilities

### New Capabilities

- `neutral-controls-and-flat-toolbars`: 模板编辑器指定工具条的中性控件和单层边界，以及范围外样式保护与识别页恢复。

### Modified Capabilities

无。现有文档缩放、识别、匹配、编辑、预设和导出行为保持。

## Impact

唯一根 `F:\App Location\Guanzhi Tong\Skill\MSDS-Engine`，页面 `http://127.0.0.1:5173/`。主要涉及 `web/src/styles.css` 和 `web/src/main.js` 的局部类与识别空态组件。无新项目、端口、依赖或 Docker 部署；数据库、草稿、批注和模板文件不能被覆盖。

最新范围以本文件与 design 的“截图范围纠偏”及当前 tasks 为准；历史全站派发/完成声明只作审计历史，不再是实施授权。
