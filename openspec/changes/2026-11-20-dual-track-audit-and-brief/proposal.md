# Proposal: 审计模块双轨优化（机械审计强化 + Agent 介入审计速查包与触发解耦）

## 目标
1. **明确区分并解耦触发时机**：Phase 4~6 覆写产出（8 份文件）完成后先确认已产出，再由 `--phase=audit` 触发**机械审计**，同时自动生成《Agent 介入审计速查包》支撑 **Agent 同步进行介入审计**。
2. **强化机械审计**：在现有 171 项基础上显式补强 **序号 / 值 / 标签 / 标题 / 说明行 / 页眉页脚** 的角色与拓扑格式区分校验，叠加字体字号、表格边框样式、PDF 渲染样式及源文件 vs 产出内容继承对照。
3. **提速 Agent 介入审计**：提炼《Pipeline + 全局/局部规范审计速查契约》并自动生成《16 章节源文 vs 中英产出对照快照》，消除 Agent 每次通读 330KB `pipeline-engine.js` 的耗时瓶颈。
