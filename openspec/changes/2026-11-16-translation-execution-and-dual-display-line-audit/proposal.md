# Proposal: 翻译底层执行写入强化与机械审计逐行双重对照显示

## 变更意图与背景
依据用户核心指示与法定核对报告 `HPU-7660_MSDS_中英文逐项翻译核对报告_Section2-16.md`，对 Section 2~16 的翻译执行写入与逐句审计通过底层逻辑进行系统性强化：
1. **翻译写入底层逻辑强化**：彻底根治 Section 9.3 pH 测试稀释条件被粗暴正则丢弃、Section 3.2 二甲基乙醇胺非标命名、Section 9.11 密度与相对密度术语失配等历史遗留翻译缺陷，确保源事实所有前置条件、测试比例与专业词汇 100% 保真转译；
2. **机械审计逐行双重对照显示 (Dual-Display)**：在机械审计程序中构建“源文件中文句 vs 产出物英文翻译句”逐行双重对照呈现引擎，结构化直观输出，自动标记对齐状态与漏译警报；
3. **智能体逐行审计硬约束**：硬化审计智能体作业准则，强制其依据五大判别基准逐行逐句举证，阻断形式主义概括放行；
4. **防回退测试套件**：建立自动化测试断言，确保 100% 满分通过且反例变异能精准熔断。
