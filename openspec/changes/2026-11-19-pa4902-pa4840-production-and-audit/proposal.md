# Proposal: PA-4902 与 PA-4840 标准七步覆写生产与全要素法医级深度审计

## 1. 业务背景与使命 (Why)
用户下达了两款新产品（`PA-4902` 与 `PA-4840`）的 MSDS 覆写生产任务。由于当前系统识别模块存在临时性缺陷（已由独立 Agent 专项修复中），本任务要求**绝对禁止盲目依赖识别模块的自动解析**，而是必须**穿透直接解读两份物理源文件 DOCX 的底层 XML 数据**，基于“内容源于源文件 + 1:1 内容继承”的受控治理原则，通过标准化七步流水线（7-Phase Pipeline）输出 16 格式标准交付物矩阵（各 4 DOCX + 4 PDF），并无条件通过双极双层全景法医审计（165 项）与集中式中央主审计套件（170 项）。

## 3. 拟变范围与不变量边界 (Scope & Invariants)
- **拟变范围**：仅在目标目录生成 16 份交付物，以及在 `scratch/` 中编写受控 facts 补全与构建脚本；
- **最高禁区**：`web/src/*` 底座引擎严禁改动；通用业务逻辑严禁私改。
