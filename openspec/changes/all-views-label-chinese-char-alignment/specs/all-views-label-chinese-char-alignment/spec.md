# 全视图表格标签中文首字绝对垂向对齐规范 (Spec)

## 规范定义

### 1. 标签网格双槽位模型 (Label Double-Slot Model)
所有表格数据行（`row.index > 0` 且非表头 `isTableHeader` 且非单列说明行 `isValueOnly`）的第一列标签单元格，必须无条件采用固定宽度的双槽位网格容器 `.label-line-grid`。

#### 需求契约：
- **GIVEN** 表格数据行中的任意第一列标签单元格
- **WHEN** 渲染该段落或单元格文本时
- **THEN** 必须输出具备 `.label-line-grid` 类名的容器
- **AND** 第一槽位必须为具备固定宽度 `--sequence-width`（2.8rem）的 `.sequence-slot`
- **AND** 若该行具备前缀序号，`.sequence-slot` 渲染该序号文本
- **AND** 若该行不具备前缀序号（例如 `中文名称：`、`供应商名称：`），`.sequence-slot` 必须渲染具备不可见占位的 `.sequence-slot.empty-slot`
- **AND** 第二槽位必须为 `.label-text-slot`，容纳标签正文文本
- **AND** 所有数据行中标签正文槽位的起始水平 X 坐标在全 16 个 Section 中保持绝对一致（垂向严格共线，偏差 0px）。

---

### 2. 模板编辑器与识别/匹配视图几何一致性 (Cross-View Geometric Consistency)
在 `01 DOCX 识别`、`02 智能匹配工作台`（原始提取表与匹配标准表）、`03 模板编辑器`中，必须使用完全一致的双槽位几何模型。

#### 需求契约：
- **GIVEN** 用户切换至 DOCX 识别、智能匹配或模板编辑器任一视图
- **WHEN** 观察表格中不同序号长度（如 `1.1`、`10.1`、`11.10`）或无序号的标签行时
- **THEN** 标签中文正文首字（如 `产`、`化`、`特`、`中`、`供`）的左边缘必须在同一垂直线上
- **AND** 模板编辑器中双击允许编辑标签时，编辑输入框的左起点必须与锁定状态下的首字起点完全重合。

---

### 3. 多行长标签悬挂缩进 (Hanging Indent)
多行长标签文本折行时，第二行及后续行严禁跌回单元格左边界。

#### 需求契约：
- **GIVEN** 文本长度超出单元格宽度的长标签（如 11.8 特异性靶器官系统毒性）
- **WHEN** 在浏览器中触发多行折行时
- **THEN** 所有续行必须严格被限制在 `.label-text-slot` 内部
- **AND** 续行文本首字必须与第一行中文首字完全垂直对齐。
