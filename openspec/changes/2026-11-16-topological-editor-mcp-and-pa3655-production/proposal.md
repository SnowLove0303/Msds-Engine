# Proposal: 拓扑编辑器 Agent 原生 MCP/ACI 工具封装固化与 PA-3655 覆写产出测试

## 1. 业务背景与治理宗旨
依据用户指示：
> “进一步固化拓扑编辑器的 Agent 原生 MCP/ACI 工具封装，使模型能够在后续复杂源文件处理中更直接、灵活地调度四层拓扑原语，并交由执行Agent使用"F:\App Location\Guanzhi Tong\Skill\MSDS-Engine\算法训练材料\源文件材料\2-1 单组份水性丙烯酸乳液 PA\PA-3655\PA-3655 msds_CN 冠志.docx" 基于最新改进的工作流进行覆写产出测试”

在前期架构演进中，系统已在 `template-editor.js` 底层实现了四大拓扑原语（内省、变形、排版、事务）。然而，在 MCP / ACI 工具层，Agent 尚无法直接通过独立强类型工具调用这些原语，仍需依赖组合复杂的 `msds_execute_editor_ops` 或由后端流水线自动处理。

本提案旨在：
1. **固化拓扑编辑器的 Agent 原生 MCP 工具层**：在 `mcp-server.js` 中新增并强化 Agent 原生工具接口（`msds_get_section_topology`、`msds_morph_section_topology`、`msds_apply_typography_ruler`、`msds_validate_topology_invariants`），使模型获得直接、细粒度调度四层拓扑原语的能力；
2. **调度执行 Agent 跑通 PA-3655 覆写产出**：获取源文件 `PA-3655 msds_CN 冠志.docx`，应用最新改进的通用产出流水线与拓扑编辑器能力，高精度导出标准 8 格式交付物（4 DOCX + 4 PDF）；
3. **法医级全景深度审计核销**：通过集中式中央主审计套件（170 项断言）、逐行双重对照显示中枢（0 报警 100% 对齐）与排版几何测试，实现零警告零缺陷的 1:1 双向物理核销。
