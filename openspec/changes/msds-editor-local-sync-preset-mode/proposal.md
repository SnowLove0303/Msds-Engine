# Proposal: 编辑器局部同步覆写模式 (Template-Agnostic Local Preset Overlay & Multi-Export)

## 1. 业务背景与现实痛点 (Background & Problem Statement)

在 MSDS 实际生产与交付业务中，存在极其普遍的 **“一源多本”** 衍生需求：
- **双发布主体并行**：同一款产品（例如 `OS-1338`），既需要出具 **广州冠志新材料科技有限公司** 的 MSDS，也需要出具 **英德市国彩新材料有限公司** 的 MSDS。
- **特定客户/定制版微调**：在保持主体一致的情况下，针对特定客户或特殊供应链要求，需要对个别字段做局部微调（例如：冠志版化学品分类为 `111`，国彩版或专供版化学品分类为 `222`，其余 15 个章节的核心数据 95% 以上完全一致）。

### 当前系统的瓶颈与痛点：
1. **割裂与重复劳动**：用户在 Web 或 Python 编辑器中完成基准版（冠志）的编辑与导出后，必须手动逐项修改字段并更换模板再次导出，容易发生遗漏或数据不同步。
2. **缺乏预设机制**：无法将“国彩主体的公司名称、地址、电话、传真、Header/Footer 编码”以及“特定分类覆写值”沉淀为可复用的预设方案。
3. **模板耦合风险（关键痛点）**：若预设简单记录在当前打开文档的物理行列坐标上，一旦用户切换模板（例如由 `CN 冠志` 换到 `CN 国彩` 或 `EN 冠志`），旧预设将瞬间失效错位。**预设功能必须跟随编辑器本身，而非跟随单一模板实例。**
4. **编辑体验割裂风险**：预设的编辑不能是一个孤立弹出的纯文本框或外部配置页，**编辑功能本身必须深度融合在已有编辑器内部**，用户在已有编辑器熟悉的界面中无缝查看、编辑覆写值，直观感知“继承基准”与“已覆写”状态。

---

## 2. 方案目标与核心原则 (Goals & Principles)

1. **编辑器层级全局预设（Editor-Level Decoupled Presets）**：
   - 预设体系存在于编辑器全局状态并实现持久化（Web 端 `localStorage`，Python 端 `editor_presets.json`）。
   - 模板切换、文件重载、页面刷新均不影响预设的存在与可用性。
2. **语义化字段抽象（Semantic Key Anchoring）**：
   - 采用标准语义键（如 `sec1.chemical_category`, `sec1.supplier.name`, `sec9.ph`, `header_footer.*`）作为覆写载体。
   - 切换任何底模时，自适应对齐引擎按语义键自动寻址，彻底免疫物理行列位移。
3. **无缝内嵌的覆写编辑体验（In-Place Editor Overlay Experience）**：
   - 在已有编辑器顶部引入「同步覆写视图选择器」与开关（`基准视图` vs `国彩预设视图`）。
   - 用户在已有编辑器的单元格中直接编辑，编辑覆写值时自动记录差量，视觉上以醒目角标与高亮提示 `[已覆写]` 与 `[继承基准]`，支持一键还原。
4. **整套模板预设支持（Template Profile Support）**：
   - 预设不仅能保存若干字段差量，还能定义衍生目标模板（例如：指定导出时采用底模 `CN 国彩` 或 `EN 国彩`）。
5. **一键多文件同步联动导出（Synchronized Multi-Export）**：
   - 导出时提供多选勾选面板（如：☑ 基准文档 `OS-1338 msds_CN 冠志.docx` + ☑ 国彩预设 `OS-1338 msds_CN 国彩.docx`）。
   - 一键生成多份标准规范的独立 DOCX 文件，实现真正的“一源多本、秒级交付”。

## 3. 影响范围 (Scope)

- **核心数据与引擎**：
  - `web/src/docx-engine.js`：增强语义键映射、衍生模板底模载入与多预设合并生成能力。
- **Web 端编辑工作台**：
  - `web/src/main.js`：预设全局持久化、编辑器内嵌图层切换、单元格差异渲染、多预设勾选同步导出对话框。
  - `web/src/styles.css`：预设工作条、覆写状态高亮微标、还原交互控件样式。
- **Python 覆写端对齐**：
  - `覆写模块/msds_template_editor.py` & `MSDS Skill 4.1`：同步支持预设持久化、已有编辑界面图层切换与批量导出。
- **自动化测试**：
  - 新增 `test_editor_sync_preset_overlay.mjs` 测试套件，验证换模板不失效、字段语义覆写与双文件导出一致性。
