# Spec: 编辑器局部同步覆写模式行为规范

## 1. 概念与定义

- **基准文档 (Base Document)**：编辑器中当前正在编辑的核心 MSDS 文档实例。
- **预设覆写层 (Preset Overlay)**：脱离具体文档实例、附着于编辑器全局配置的差异集与模板画像，包含目标底模绑定、页眉页脚覆盖包及语义键覆写字典。
- **语义键 (Semantic Key)**：跨模板通用的规范化字段标识符（例如 `sec1.chemical_category`），不与物理行号列号绑定。

---

## 2. 需求规范与验收准则 (Acceptance Criteria)

### 场景 1：预设的独立持久化与模板抗毁性
- **Given** 用户在当前编辑器中配置了预设【国彩主体】，并对 `sec1.chemical_category` 设定了覆写值 `222`。
- **When** 用户在模板选择下拉框中从 `CN 冠志` 切换为 `CN 国彩` 或 `EN 冠志`，或者刷新浏览器页面。
- **Then** 预设【国彩主体】必须完好保留在预设列表中，且在切换后的模板上依然能准确命中该字段，无数据丢失或行列错位。

### 场景 2：已有编辑器内嵌编辑与双态感知
- **Given** 用户开启了【同步覆写模式】，并在顶部图层下拉框中选中了【国彩主体】。
- **When** 用户浏览已有编辑器的各个章节单元格。
- **Then** 未修改的字段显示基准值并带有 `[继承基准]` 提示；用户编辑该字段后，其状态立即转变为 `[已覆写]` 并高亮显示；点击 `[↺ 还原]` 可清除该覆写并重新恢复继承基准值。

### 场景 3：整套模板预设与主体联动
- **Given** 预设【国彩主体】绑定了目标底模 `CN 国彩` 及国彩公司信息。
- **When** 用户在基准版（冠志模板）中录入产品型号为 `OS-1338`、分类为 `111`。
- **Then** 该预设自动继承基准型号 `OS-1338`，但在主体公司、地址、电话、传真及页眉页脚上自动采用国彩规范，分类采用覆写值 `222`。

### 场景 4：同步勾选导出多文件
- **Given** 用户在主编辑器中完成了基准版编辑，且预设【国彩主体】已配置。
- **When** 用户点击【同步覆写导出】并同时勾选【基准版】与【国彩主体预设】。
- **Then** 系统必须同时输出两份合规的 DOCX：
  1. `OS-1338 msds_CN 冠志.docx`（含分类 `111`，冠志页眉页脚与供应商信息）。
  2. `OS-1338 msds_CN 国彩.docx`（含分类 `222`，国彩页眉页脚与供应商信息）。
