# OpenSpec Proposal: Section 11 实测毒理端点零损耗保全与反标签前缀叠词工业级闭环

## 一、 背景与动因 (Why)
在 PU-202A（单组分危险品）交付物审查中，发现 Section 11 存在严重的数据与格式缺陷：
1. 急性毒性丢失关键的“经皮毒性 (Dermal)”与“吸入 4h 测试数据”；
2. 多个单元格值开头重复出现左列大标签前缀（`吸入：吸入：`、`致癌性：致癌性：`、`特异性靶器官...：特异性靶器官...：`）；
3. 11.2 标签术语被底模篡改为“原发性皮肤刺激”，未遵循源文件“主要皮肤刺激性”；
4. 审计脚本 `audit_bipolar_bilayer.mjs` 缺少对上述规范的物理级硬断言，造成虚假全绿通过；
5. 新发现的规则未区分沉淀至全局通用规范与局部专属规范。
