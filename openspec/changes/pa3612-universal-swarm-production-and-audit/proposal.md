# Proposal: PA-3612 通用受控工作流 Swarm 协同生产与两阶深度审计

## Why
用户指令针对 `PA-3612` 源文件开展生产与交付物全量产出任务。必须落实系统两大核心架构升级：
1. 彻底打破底层硬编码冠志/国彩的假通用，以模板（Templates）与预设（Presets）作为外部工作情境驱动；
2. 彻底废止 5900 行旧 `pipeline-engine.js` 依赖，以透明轻量的 `recognition-engine.js` + `context-governor.js` + `editor-writer.js`（万能原语）为执行核心；
3. 落实 Swarm 协同分工：由 Swarm Worker（`producer`）负责极速装配产出，Coordinator 负责全程监控与两阶全景深度终审（机械 159 项 + 16 章节双语保真）。

## What Changes
1. **源事实感知**: 锁定 `PA-3612` 源文件并无损解析为客观 `Context1`；
2. **事实治理**: 通过 `context-governor.js` 实施 GHS 零外生虚增、丙烯酸体系化学品专业英译（`Acrylic resin` / `Deionized water`）与运输信息映射生成 `Context2`；
3. **Swarm 协同装配**: 派出 Swarm Agent 调用 `writeDeliverableViaEditor` 与企业预设，极速装配中文/英文正式交付物；
4. **Coordinator 终审**: 执行 159 项集中式主审计与 16 章节双语逐行保真审计，出具 1:1 双向物理核销矩阵。
