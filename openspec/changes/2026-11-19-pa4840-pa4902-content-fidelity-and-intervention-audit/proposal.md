# Proposal: PA-4840 与 PA-4902 源文件原文、识别结果与产出物内容继承闭环与全景介入审计

## 1. 提案背景与依据
依据用户明确指令：
> “对照 4840 4902 源文件原文、识别结果、产出物 ，修复4840 4902 内容缺失等问题，做好介入审计；目前识别模块问题到编辑模块的通用性问题特别大，围绕识别模块、编辑模块和底层拓扑以及审计、工作流等做优化；拓扑产出的内容基本没问题，但是存在新增内容，可能丢失格式，需要考虑一些可能的情况，以及审计一定要做好；F:\App Location\Guanzhi Tong\Skill\MSDS-Engine\识别模块\识别模块训练夹 这是4840 4902的源文件内容，优化好识别模块；做好两道门禁直接推进，明天来验收，底层功能代码优化好推送到仓库（产出别推）”

在法医级三方对账（源文件留存 vs 识别结果 vs 最终产出物）中，发现关键事实在流水线中发生衰减与格式丢失：
1. **PA-4902 第 2 部分重大截断**：源文件明确具备警告词（警告）、危害性说明（没有明显的已知作用或严重危险。）、15 句散文防范说明与 3 项其他危害，识别模块已提取，但在 `context-governor.js` 与 `production-orchestrator.js` 中因 `isNonHazardous` 被粗暴清空，并在 `editor-writer.js` 中被硬编码覆盖为单行“根据GHS不属于危险物”；
2. **PA-4902 第 3 部分成分附注丢失**：第 5 行关于成盐中和剂（`N,N-二甲基乙醇胺，中和剂，已键合为盐...`）的关键法规附注被 `editor-writer.js` 截断丢弃；
3. **新增内容样式丢失问题**：在拓扑写入中，动态新增的段落或行（如附注行、防范说明多行）缺失 Design Tokens 样式投影（字体、字阶、行高、边框、垂直居中），导致格式受损；
4. **PA-4840 标签要素与毒理学数据核销**：确保 2-丁氧基乙醇有害成分标签标注与 20 行高维毒理学试验数据 100% 完整继承；
5. **双语对账与理化稀释比**：Section 9 稀释比（4840 为 1:1，4902 为 1:10）在中英文中精准继承；
6. **全生命周期三方介入审计体系**：开发 `agent_intervention_audit.mjs`，执行机械化与认知审计，达成 Exit Code 0。
