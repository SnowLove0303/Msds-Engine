# Proposal: 重构最终工作流审计流程并编入 Agent 审计任务 1（内容审计 / 合并版 Context 3）

## 1. 背景与目标
在 MSDS 标准化交付流水线中，仅靠产出脚本自检或分散的文本比对无法稳定发现跨章节内容缺失、翻译偏差或非预期结构退化。根据用户指令与 Gate 1 确认结果，现重构最终工作流的审计阶段（`msds-studio/SKILL.md` Phase 10 / 阶段 6），正式设立 **Agent 审计任务序列**，并将基于同源识别模块（`msds_recognize_source` / `recognition-engine.js`）的 **Context 3 中英文合并识别与内容审计** 编入 **Agent 审计任务 1（内容审计）**。
