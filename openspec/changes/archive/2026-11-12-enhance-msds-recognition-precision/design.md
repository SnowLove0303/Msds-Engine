# Design: MSDS Recognition Precision Enhancement & Hierarchical Penetration

## 一、技术方案与状态机设计 (State Machine & Algorithm)

```
┌────────────────────────────────────────────────────────────────────────┐
│ detectSectionHeaderInRow 升级: 容差前缀匹配 (^\s*(?:v|V)?\s*(\d{1,2})...)│
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 命中章节标题并清洗掉杂质 'v'
┌──────────────────────────────────▼─────────────────────────────────────┐
│ 复合单元格层级穿透器: decomposeMultiLineCellRows(row, secNum)            │
│ 针对 Section 2: 拆解多行段落为                                         │
│ • 一级子题头: "物质或混合物分类"                                        │
│ • 二级标签/值: "GHS分类：" -> "根据GHS不属于危险物"                     │
│ • 二级标签/值: "GHS象形图：" -> "根据GHS不属于危险物"                   │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 逐行打标
┌──────────────────────────────────▼─────────────────────────────────────┐
│ 上下文感知分类器: classifyRowSemanticType                             │
│ • 引导语模式判定: /风险评估|其它规定|法规要求/ -> 说明行                │
│ • 续行长句判定: 无冒号且无后续值格 -> 说明行 (如 5.3 烟尘警告)         │
│ • 标签值拆分: 含有冒号且短文本 -> 标签 + 值                           │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 二、拟变范围清单因果角色 (Causal Topology)

1. **[Root Source] 识别引擎正则与穿透算法升级 (`web/src/recognition-engine.js`)**：
   - 升级 `detectSectionHeaderInRow` 支持可选 `v/V` 前缀并规范化输出；
   - 增加 `isPreambleGuidanceText` 检测引导语（如“类似产品的风险评估数据：”）；
   - 在 Section 2 处理中支持将单一单元格内的多行文本智能展开为多条独立的层次化记录；
   - 修复无冒号单列长句（如“在着火或爆炸情况下，不要吸进烟尘。”）的分类逻辑，判定为 `说明行`。
2. **[State Transition] Context 1 Markdown 序列化器同步对齐**：
   - 确保 `serializeFactsToMarkdown` 将穿透拆解后的层次化记录以清晰规范的行号呈现。
