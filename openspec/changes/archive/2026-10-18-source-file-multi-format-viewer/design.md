# Design: 智能匹配多格式开源阅览器接入与 UI 宽度自适应架构

## 1. 阅览引擎选型与接入设计 (GitHub Top Choice)

经过对 GitHub 开源生态的全面检索，采用行业 Star 最高的顶流开源组合：

```
                    源文件导入 (.docx / .doc / .pdf)
                                   │
                      文件类型检测与引擎分发器
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
      [.pdf]                    [.docx]                   [.doc]
         │                         │                         │
 46k+ Star 标杆             2.1k~4.2k Star            项目自备极简 COM 桥
 Mozilla PDF.js             docx-preview /           (Win Word/WPS) 导出
 + 浏览器原生沙箱          @js-preview 增强引擎               │
 (100% 打印矢量原版)        (自适应分页与流式排版)              ▼
         │                         │                  高保真 PDF 预览流
         └─────────────────────────┼─────────────────────────┘
                                   ▼
                    【源文件原版式】统一视口
               (智能宽度自适应 / 聚焦展宽 / 无损缩放)
```

1. **PDF 阅览层 (PDF.js / 原生 PDFium)**：
   - 依赖项：集成 GitHub 46k+ Star 绝对标杆 `mozilla/pdf.js` 与现代浏览器原生高保真沙箱；
   - 渲染模式：通过本地 Blob URL 挂载，直接呈现真实 A4 矢量分页与高精度表格排版，毫秒级就绪；
   - 内存管理：挂载全局句柄追踪，文件切换时调用 `URL.revokeObjectURL` 彻底释放。
2. **DOCX 阅览层 (增强型纯前端流)**：
   - 保留并升级现有轻量引擎，优化 A4 纸张页面投影与表格撑满；
   - 结合 CSS `zoom` 与 `transform` 动态补偿，保证大中小屏幕字体清晰锐利。
3. **DOC 适配层**：
   - Windows 本地优先尝试调用本地 Word/WPS 导出原生 PDF 流（复用 `识别模块` 逻辑）；
   - 离线环境无依赖时弹出指引模态框。

## 2. UI X 轴宽度分配与防截断架构

### 2.1 列宽权重重构
当前问题：`1fr : 1.15fr : 1fr` 过于平均，导致原版式仅有 ~400px，A4 页面严重缩水或被裁切。
改进方案：
```css
/* 三屏同览科学权重：倾斜供给给真实原版式列 */
.matching-grid-all-three {
  display: grid;
  grid-template-columns: minmax(280px, 0.85fr) minmax(320px, 1fr) minmax(520px, 1.45fr);
  gap: 12px;
  align-items: stretch;
}
```
* 原始识别表格列（纯文本表格数据）：占 0.85fr，紧凑展示即可满足核对需求；
* 标准模板匹配列（标准插槽）：占 1.0fr，保证字段与状态完整可视；
* **源文件原版式列**：占 **1.45fr**（保底 $\ge 520\text{px}$，在 1080P/2K 屏幕下可达 $700\text{px} \sim 950\text{px}$），使 A4 页面能以逼近 1:1 的自然原貌舒发展现。

### 2.2 彻底解除 X 轴死锁与裁切
* 移除所有 `.docx-preview-shell` 与容器的 `overflow-x: hidden !important;`；
* 改为 `overflow-x: auto`，并优化轻量滚动条样式；
* 优化 `applyDocxFitToWidth` 算法：默认按容器当前实际宽度精准充满（`fit` 模式下 scale 自适应计算，不留任何浪费的白边）。

### 2.3 “聚焦展宽”双态工作区
在原版式栏目顶部新增聚焦控制：
* **标准三屏态 (Default)**：0.85fr : 1.0fr : 1.45fr；
* **展宽聚焦态 (Expanded)**：0.4fr : 0.6fr : 2.0fr（或原版式独占 70% 宽幅），用户在细查密集化学式或复杂表格时一键开启，审阅完毕一键复原。
