# Design: 实际案例驱动的智能匹配引擎与标签/值判定深度优化

## Context
真实生产环境中的 MSDS 文档格式高度异构。在 `F:\MSDS覆写\MSDS\TDS MSDS (2)` 的实际案例测试中，水性聚氨酯（PU）与丙烯酸树脂（PA）等样例暴露了加粗被误分类为标签导致值丢失、特有理化指标脱靶、结构化毒理块无法聚合等问题。
本设计遵循 `MSDS匹配规则体系 · 全局与局部深度辨析报告` 的防火墙原则，在底座层与各章节策略插件层进行两级解耦优化。

## Architecture

### 1. 底座词法解析层（`docx-engine.js`）中的 `cellRole` 升维

```
                       ┌─────────────────────────┐
                       │     单元格段落解析      │
                       └────────────┬────────────┘
                                    │
                                    ▼
                       ┌─────────────────────────┐
                       │   检测到加粗文本段落    │
                       └────────────┬────────────┘
                                    │
               ┌────────────────────┴────────────────────┐
               ▼                                         ▼
      【字数 <= 10 或带冒号】                   【字数 > 10 且无冒号】
      【或属于明确章节主标题】                  【或处于非首列且无标签特征】
               │                                         │
               ▼                                         ▼
     归为 Label (labelText)                     归为 Value (valueText)
     (作为槽位匹配索引键)                      (保留实质数据，防内容被掏空)
```

- **判别准则**：
  1. `isLabelCandidate`: 文本长度 `<= 10` 字符，或者末尾带有中文冒号/英文冒号（`/[：:]$/`），或者是合法的前缀编号章节标题（如 `1. 物料及供应商标识`）；
  2. 凡长度 `> 10` 且无冒号结尾的加粗文本，自动识别为加粗强调的**值（Value）**，存入 `valueParts`；
  3. 纯标点符号过滤：如果加粗内容仅仅是标点符号（如 `^[\s\p{P}]+$`），直接剔除，严禁产生独立伪标签；
  4. 首列与后续列隔离：`cell.col > 0` 的单元格，若没有明确的键值冒号结构，默认归入 `valueText`。

### 2. 局部匹配策略插件层（`smart-matching.js`）深化

1. **树脂专有理化指标适配（Section 9）**：
   - 增加专有指标别名组：
     - `mfft`: `['最低成膜温度', '最低成膜温度mfft', 'mfft', 'minimum film forming temperature']`
     - `tg`: `['玻璃化温度', '玻璃化转变温度', 'tg', 'glass transition temperature']`
     - `hydroxyl_value`: `['羟值', '羟基值', 'hydroxyl value', 'hydroxyl number']`
   - 将其解析出的数据以标准格式（如 `最低成膜温度(MFFT): 30℃`）归入理化特性槽位或 `other_info`，并在模板中安全保留。
2. **结构化毒理学研究试验块聚类（Section 11）**：
   - 遵循 OW-161 规约：识别以“物种”、“分类”、“结果”、“方法”组织的测试研究块；
   - 识别出志愿者接触无过敏试验后，聚合生成 `人类皮肤接触试验：不是皮肤过敏物质，证明没有过敏特性`，写入 `sensitization`（皮肤致敏）；
   - 遵循 OW-055 规约：识别“该产品无可用的毒理学研究”，作为节级说明上下文保留。
3. **散文智能语义定向路由器**：
   - S5：增加“不要吸进烟尘 / 爆炸烟尘”定向到防护措施；
   - S8：增加“无可用的接触限值信息”定向到职业接触限值；
   - S13：增加“欧洲废弃物分类 / EWC”定向到废弃处置方法；
   - S15：增加“GB 20576 / GB 30000 / GB 15258”定向到法规清单。
4. **Section 3/4 跨表流转调度器**：
   - 在解析 Section 3 表格记录时，前置扫描行内容，若发现从某一行开始出现“4.急救措施”或“误服/接触眼睛/接触皮肤/吸入”，将这批行切出并派发至 Section 4 的源事实队列中进行标准化匹配。

## Verification Strategy
- 扩充 `tests/diagnose_samples.mjs`，覆盖聚氨酯（PU-1007、PU-1036 CN/EN、PU-202A）与丙烯酸（PA-3617、PA-3615）；
- 校验指标：
  - 加粗长值丢失率降为 0；
  - Section 9 MFFT/Tg 匹配成功率达 100%；
  - Section 11 结构化毒理研究块命中率达 100%；
  - UNMATCHED 总体比例降低 50% 以上；
  - `npm run test:smoke` 和 `npm run build` 全绿。
