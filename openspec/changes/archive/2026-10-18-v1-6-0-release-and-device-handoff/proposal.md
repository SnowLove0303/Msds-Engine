# Proposal

## Why

自 v1.5.0 以来，MSDS-Engine 完成了多项核心能力的突破与系统级加固：
1. **Linux 容器高保真 PDF 导出管道**：补充 `docker/fonts` 与 `fontconfig` 配置，在容器内打通 LibreOffice 无头转换与预检自愈机制，实现 Word+PDF 一体化交付；
2. **预览视口灰框彻底根除与自适应缩放修复**：穿透覆盖三方库动态注入的 `background: gray` 30px 深灰粗框，修复 `applyDocxFitToWidth` 选择器，实现三视图纯白无缝连续与等比缩放；
3. **OpenSpec 全量规范归档**：34 项历史变更全部安全闭环归档，主规格契约完全同步；
4. **跨设备开发诉求**：用户需要在另一台设备上继续无缝开发，必须固化当前全部产物、递增版本至 `v1.6.0`、打标签并推送到 GitHub 远程仓库。

## What Changes

1. **版本升级**：将 `web/package.json` 版本号提升至 `1.6.0`；
2. **发布与交接文档**：
   - 编写 `RELEASE_NOTES_v1.6.0.md`，汇总关键变更；
   - 更新 `web/项目交接文档.md`，提供另一台设备的快速克隆、环境准备、Docker 一键启动与开发接入指南；
3. **质量门禁与测试**：执行背景契约断言、运行时计算样式测试与构建检查；
4. **Git 提交、标签与推送**：
   - 提交全部代码、规约与测试资产；
   - 创建 Git 语义发布标签 `v1.6.0`；
   - 推送 `main` 分支与发布标签至 GitHub 远程仓库（`SnowLove0303/Msds-Engine`）；
5. **交付跨设备交接清单**：整理在新设备上的拉取、启动与验证步骤。

## Capabilities

### Modified Capabilities

- `github-v1-release`: 扩展发布契约，支持 v1.6.0 版本递增、多格式交付能力固化与跨设备交接验证。

## Impact

- 远端仓库：GitHub 仓库同源同步最新完整状态与 `v1.6.0` 标签；
- 本地环境：代码库完全干净、无未跟踪悬空文件；
- 跨端协作：另一台设备可直接 `git pull` 并拉起容器无缝续接。
