# Proposal: PU-202A 通栏标准 8 格式全量交付与格式继承

## 1. 业务动机与背景
用户在审阅 `29d1acd7-309a-4775-b722-78688bb1d302` 会话产出时发现，由于旧 Skill 与代码中存在“危险品/单组分强制保持 18 行分列”的限制，导致 PU-202A 依然采用了分列排版。实际上，源文件本身的 Section 2 即为单单元格通栏，且最新立法确立的《通栏标准准则（G-32）》要求所有型号无论危险品与否均采用通栏写法，忠实继承编辑器模板编辑的标签-值文本格式。

## 2. 核心目标
1. **Section 2 危险品通栏装配**：收敛为 2 行（Row 0 章节大标题 + Row 1 单单元格通栏，`gridSpan="2"`, `w="9795"`），完整继承 GHS 6 大危险分类、象形图 DrawingML 图元迁移、信号词“危险”、6 项 H 编码与四大防范说明 P 码，严格落实 5 级缩进与粗细分离；
2. **Section 11 毒理学三级责任隔离通栏装配**：收敛为 4 行（Row 0 标题 + Row 1 免责通栏 + Row 2 DMAC 前言通栏 + Row 3 DMAC 实测毒理通栏，均为 `gridSpan="3"`, `w="9781"`），组分大标题加粗，试验数据指标垂向对齐且正文全常规体；
3. **交付目录绝对纯净门禁 (G-01 Purity)**：`算法训练材料/PU-202A/` 严格有且仅有 8 个法定交付物；
4. **全景双审计全绿**：通过 `audit_bipolar_bilayer.mjs` (双极双层) 与 `run_four_dimensional_audit.mjs` (四维深度审计)。
