# Spec: PU-202A 通栏标准 8 格式规范 (PU-202A Full-Width Purity Spec)

## 规范定义
1. **Section 2 危险品通栏规范**：
   - 表格行结构：Row 0（章节标题，跨 2 列） + Row 1（单单元格通栏，`w:gridSpan="2"`, `w:w="9795"`）；
   - 标签-值装配流：
     1. `2.1 GHS危险性类别：`（粗体标签），6 项危险分类常规体独立换行；
     2. `2.2 GHS标签要素：`（粗体引导）；
     3. `GHS象形图：`（跨文档无损克隆嵌入 GHS08、GHS07、GHS05 图元，居中对齐）；
     4. `信号词：危险`（标签粗体，值常规体）；
     5. `危险性说明：`（粗体引导），各项 H 语句常规体；
     6. `防范说明：`（粗体总标题）；
     7. 四大防范子标题（`预防措施：`、`事故响应：`、`安全储存：`、`废弃处置：`，粗体，5 级缩进）；
     8. 各具体 P 语句（常规体，按 5 级缩进与垂向首字对齐排版）；
     9. `其他危险：无适用资料。`（标签粗体，值常规体）。

2. **Section 11 毒理学三级责任隔离通栏规范**：
   - 表格行结构：4 行结构（均为 `w:gridSpan="3"`, `w:w="9781"`）；
   - Row 1: 产品级免责通栏（`该产品无可用的毒理学研究。`，常规体，`jc="left"`）；
   - Row 2: 原料前言通栏（`以下是N,N－二甲基乙酰胺毒理学数据：`，常规体，`jc="left"`, `w:left="34"`）；
   - Row 3: 组分实测毒理通栏（仅组分标题加粗，试验数据正文全常规体，经口/吸入/皮肤/粘膜等指标首字垂向对齐）。

3. **G-01 交付目录绝对纯净断言**：
   - 目标目录 `算法训练材料/PU-202A/` 中非目录物理文件总数恒等于 8，完全由 4 份 DOCX + 4 份 PDF 组成，严禁出现 `_源文件留存`、`(最新)`、`(更新)` 等碎片。
