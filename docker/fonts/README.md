# docker/fonts — 镜像构建用的原中文字体

本目录用于在**构建镜像时**把文档实际使用的中文字体装入容器。

## 为什么必须用原字体

容器内若用度量不同的替代字体渲染中文，换行点会改变、分页随之漂移。
同一份 PU-303C 金标样本实测：

| 渲染字体 | 页数 | 与 Word 金标 |
|:--|--:|:--|
| 替代字体（Noto CJK） | 12 | 不一致 |
| 原字体（宋体/黑体/楷体） | 7 | **完全一致** |

## 需要放入的文件

从宿主机 `C:\Windows\Fonts\` 拷贝（约 67 MB）：

    simsun.ttc  宋体 / 新宋体
    simhei.ttf  黑体
    simkai.ttf  楷体
    simfang.ttf 仿宋
    msyh.ttc    微软雅黑

`scripts/sync-build-fonts.ps1` 可一键完成拷贝。

## 合规提示

这些字体为微软专有字体，**不得随开源仓库或对外分发的镜像传播**：

- 已在 `.gitignore` 中排除（仅 `.gitkeep` 与 `README.md` 入库）；
- 含这些字体的镜像仅限公司内部使用；
- 对外交付请改用不含字体的构建方式（PDF 分页将与 Word 存在差异），或在目标环境自行安装字体。
