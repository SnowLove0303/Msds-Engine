## 1. 项目定位

MSDS Studio 是一个完全在浏览器本地运行的 MSDS 工作台，用于把现有的两个 Windows/Python 模块集中到一个网页中：

- DOCX 识别：导入 MSDS `.docx`，解析 16 个 Section，显示结构化表格和源 DOCX 原版式。
- 模板编辑器：基于内嵌 CN 冠志 / EN 冠志模板，编辑非加粗值，保护标签、序号和结构，并导出新的 DOCX。

浏览器端不上传文件，不依赖后端服务，也不会覆盖用户原始 DOCX 或内嵌模板。

## 4. 前端技术结构

### 4.1 `src/docx-engine.js`

核心职责：

- 使用 JSZip 读取 `.docx` ZIP 包。
- 读取 `word/document.xml`、`styles.xml`、`settings.xml`、`numbering.xml`、页眉页脚和关系文件。
- 解析：
  - 表格、行、单元格、列宽。
  - `gridSpan`、`vMerge`、行高、单元格宽度。
  - `w:tblBorders`、`w:tcBorders`、`w:shd`、单元格边距。
  - 段落对齐、缩进、间距和行距。
  - run 字体、字号、加粗、斜体、颜色、下划线、删除线。
  - 图片关系和图片尺寸。
  - Word 自动编号 `w:numPr` 和 `numbering.xml`。
- 保留原始 XML 证据和解析警告。
- 在内存工作副本中修改值并导出新的 DOCX。

### 4.2 `src/main.js`

核心职责：

- 顶部导航和两个工作区状态。
- DOCX 文件选择和拖拽导入。
- 16 个 Section 目录。
- 结构化识别表格渲染。
- 原 DOCX 版式预览。
- 模板编辑器字段绑定、增删行、标签锁定、审计和导出。

### 4.3 `src/styles.css`

当前界面原则：

- 白色背景。
- 低装饰、少说明。
- 识别区三列同高，目录、识别表格、原版式分别在各自区域滚动。
- 识别表格使用 Excel 风格的共享边线：
  - 相邻单元格共用一条边。
  - 不绘制两条重叠边。
  - 外框统一实线。
  - 内部横线、竖线统一实线。

## 5. DOCX 识别规则

### 5.1 Section 识别

- 普通标题：`1.物料及供应商标识`、`2.危险性概述` 等。
- 旧式 Section 1：`v1.物料及供应商标识` 会识别为 Section 1，网页显示为 `1.物料及供应商标识`。
- 英文模板通过英文标题别名识别 Section 1–16。
- Word 自动编号通过 `w:numPr` 和 `numbering.xml` 解析。

### 5.2 序号显示

识别结果中的序号显示规则：

- 统一为 `1.1` 形式。
- 不显示多余的 `·` 或其他尾部符号。
- 序号与标签之间使用固定间隔。
- 序号字号略小于标签。
- 序号与标签在同一个第一列文本流中，不创建独立序号列。
- 右侧原版式保持原 DOCX 的真实显示。

### 5.3 标签和值

识别结果采用角色级文本格式：

- 加粗 run：标签。
- 非加粗 run：值。
- 标签统一使用文档标签角色的字体和小四字号，并保持加粗。
- 值统一使用文档值角色的字体和小四字号，并保持非加粗。
- 一个值单元格可以包含多个段落和多行，不会因为换行自动增加表格行或横线。
- 原始混合 run 仍保留在 JSON 和源预览中。

### 5.4 无标签续行和独立行

只有满足下面条件时才合并续行：

```text
当前源行第一列为空
当前源行后续列有值
上一行存在明确的标签-值结构
```

例如 Section 5：

```text
物质或混合物的特殊危害： | 燃烧时释放……
空白                   | 在着火或爆炸情况下，不要吸进烟尘。
```

第二行会合并到上一行的值单元格。

而 Section 8 的下列内容是独立行，不会合并：

```text
氟化橡胶 –FKM:  厚度≧0.4mm；穿透时间≧480min.
丁基橡胶 –IIR： 厚度≧0.5mm；穿透时间≧480min.
丁腈橡胶 –NBR： 厚度≧0.35mm；穿透时间≧480min.
```

因为它们本身有独立的第一列文字和标签分隔符。

### 5.5 表格线

识别结果不再依赖源文件的 `nil`、`dotted`、`dashed` 线型，统一使用 Excel 风格：

- 外框：实线。
- 横向分隔：实线。
- 纵向分隔：实线。
- 相邻单元格共享边线。
- 合并单元格保留 `rowspan` / `colspan`。
- 段落换行不会增加内部表格线。

## 6. 模板编辑器规则

- 默认打开 CN 冠志模板。
- 可以切换 EN 冠志模板。
- 默认只允许修改非加粗值。
- 加粗标签、章节标题、序号和结构行默认锁定。
- 开启“特殊情况：允许修改标签文本”后，才允许修改标签。
- Section 9 标签保持固定宽度序号前缀。
- 新增行复制原行结构并清空可编辑值。
- 删除操作禁止删除章节标题和最低结构行。
- 导出前执行连续编号和结构审计。
- 导出生成新文件，不覆盖源模板。
