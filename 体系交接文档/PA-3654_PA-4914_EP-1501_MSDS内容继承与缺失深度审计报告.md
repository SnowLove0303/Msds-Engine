## 二、 跨型号全局系统性共性缺陷清算 (Universal Systemic Omissions)

经白盒交叉解包与字符级扫描，发现在三个产品的重写版产出物中，均存在以下母版级的系统性遗漏：

### 1. 【通用严重缺失】中文版第 1 节“化学品分类”右侧单元格 100% 彻底空白
- **实测底层 XML 证据**：
  - `PA-3654 msds_CN 冠志.docx` Table 0 Row 3: `化学品分类： | `（值格为空）
  - `PA-4914 msds_CN 冠志.docx` Table 0 Row 3: `化学品分类： | `（值格为空）
  - `EP-1501 msds_CN 冠志.docx` Table 0 Row 3: `化学品分类： | `（值格为空）
- **源文件真实事实**：
  - PA-3654 源文件明确记载：`化学品分类： | 改性丙烯酸乳液`
  - PA-4914 源文件明确记载：`化学品分类： | 丙烯酸聚合物`
  - EP-1501 源文件明确记载：`化学品分类： | 环氧水分散体`
- **根因技术穿透**：底层模板前置清零将 `化学品分类：` 右侧清空，但流水线回填映射中缺少 `chemical_category` 针对中文版的绑定逻辑，而英文版因存在默认转译（如 `Epoxy water dispersion.` / `Aqueous acrylic dispersion.`）得以填充，导致中文版交付物全部**实质性丢失了核心化学品定性信息**。

### 2. 【通用语义漂移】应急电话被粗暴降级并伪装为“传真”
- **实测底层 XML 证据**：
  - PA-3654 源文件明确并列记载：
    - `联系电话： | 86-20-82567990`
    - `应急电话： | 86-20-32214789`
  - 中文产出物机械套入模板后变为：
    - `电话： | 86-20-82567990`
    - `传真： | 86-20-32214789`
- **审计判定**：我国《化学品安全技术说明书 内容和项目顺序》(GB/T 16483-2008) 强制要求载明“应急咨询电话”。产出物将应急电话粗暴篡改为“传真”，导致**法定应急咨询责任槽位实质性缺失**。

### (一) PA-4914 (水溶性羟基丙烯酸树脂) 深度剖析

PA-4914 作为易燃液体树脂（闪点 $\sim 38^\circ\text{C}$，UN 1866），在内容继承上面临最严重的合规缺陷，共有 **3 项致命级缺陷**与 **2 项严重级遗漏**：

#### 1. 🚨 Section 8.2 工程控制措施 100% 彻底为空 (DEF-01)
- **源文件背景与合规要求**：闪点 $\sim 38^\circ\text{C}$ 的闭杯易燃液体，极易积聚挥发性易燃蒸气，必须具备局部排风、通风设备、安全淋浴和洗眼器等工程控制防范条文。
- **产出物实测表现**：
  - 中文版 Table 7 Row 11: `8.2 工程控制： | `（右侧单元格字符数为 0，完全空白！）
  - 英文版 Table 7 Row 11: `8.2 Engineering controls: | `（右侧单元格字符数为 0，完全空白！）
- **根因分析**：`smart-matching` 模块抓取失败后以空字符串强行覆盖母版，且无后置校验拦截，导致工程控制安全说明全量丢失。

#### 2. 🚨 Section 8 工作场所职业接触限值数据行完全为 0 (DEF-02)
- **源文件原文记载**（Table 7 Rows 3-5）：
  ```text
  物质       | 标准来源 | 类型  | 数值
  丙二醇甲醚 | ACGIH    | TLVTN | 100ppm,606 mg/m3
             |          | TLVWN | 150ppm,909 mg/m3
  ```
- **产出物实测表现**：
  - 中文版 Table 7 Rows 12-13 仅生成两行：
    - Row 12: `工作场所组分控制参数`
    - Row 13: `物质 | 依据 | 类型 | 数值`
    - **Row 14 及下方：0 行数据！**
  - 英文版 Table 7 Rows 12-13 同样仅有表头：
    - Row 12: `Control parameters for workplace components.`
    - Row 13: `Substance | Basis | Type | Value`
    - **Row 14 及下方：0 行数据！**
- **根因分析**：数据提取脚本仅识别了 PMA 缩写，未能识别 PGME / 丙二醇甲醚，匹配失败后直接清空了数据行，导致源文件明确载明的职业限值数据彻底丢失，表格断头悬空。

#### 3. 🚨 Section 14.2 英文版运输正式名称 100% 空白 (DEF-03)
- **源文件原文记载**：`联合国运输名称： | 树脂溶液，易燃`（对应 UN 1866 的官方正式运输名称为 `RESIN SOLUTION, flammable`）。
- **产出物实测表现**：
  - 中文版 Table 13 Row 2: `14.2 联合国运输名称： | 树脂溶液，易燃`
  - 英文版 Table 13 Row 2: `14.2 UN proper shipping name: | `（**完全空白！**）
- **根因分析**：英文模板中未配置运输名称英文映射槽位，流水线未做英译填充，导致英文版正式运输名称缺失。

#### 4. 🔴 Section 2.1 危险分类中丢失“急性毒性，吸入，类别3” (DEF-04)
- **源文件原文记载**：GHS分类明确包含：
  `易燃液体，类别3`、`严重损伤/刺激眼睛，类型2A`、`特异性靶器官毒性（一次性接触），类别3`、`急性毒性，经口，类别5`、**`急性毒性，吸入，类别3`**、`腐蚀/刺激皮肤，类别3`。
- **产出物实测表现**：流水线输出为：
  `易燃液体，类别 3（H226）`、`急性毒性（经口），类别 5（H303）`、`吸入危险，类别 2（H305）`、`皮肤腐蚀/刺激，类别 3（H316）`、`严重眼睛损伤/眼睛刺激性，类别 2A（H319）`、`特异性靶器官系统毒性 一次接触，类别 3（H336）`。
- **审计判定**：流水线为了强行凑齐 H305 语句，单方面删除了源文件的 `急性毒性，吸入，类别3`，篡改并遗漏了源文件载明的吸入急性毒性分类。

#### 5. ⚠️ Section 1.1 英文品名缺失核心型号代码 `PA-4914` (DEF-05)
- **产出物实测表现**：中文版为 `水溶性羟基丙烯酸树脂 PA-4914`；英文版 Table 0 Row 1 仅写为 `Water-soluble hydroxy acrylic resin.`，**丢失了型号代码 `PA-4914`**。
